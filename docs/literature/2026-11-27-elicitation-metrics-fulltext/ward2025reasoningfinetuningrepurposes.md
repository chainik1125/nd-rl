# Ward et al. 2025, "Reasoning-Finetuning Repurposes Latent Representations in Base Models" (arXiv 2507.12638v1)

Page numbers are PDF pages (`=== page i/8 ===`). This is a short workshop paper; many settings are not given.

## How the vector is built

- **Difference of means (DoM)** (p2 section 2.1; p7 Appendix A, Eq. 3): `v = MeanAct(D+) - MeanAct(D)` where `MeanAct(D) = (1/|D|) sum_i (1/|S_i|) sum_{s in S_i} A(p_i)[s]`, `A(p_i)` is the hidden state at the target layer when forward-passing prompt/trace `p_i`, `S_i` the chosen sequence positions, and `D+` the subset where a backtracking token is present (annotated by GPT-4o).
- The contrast is therefore "positions before backtracking sentences" versus "positions across all sentences" (D+ is a subset of D, so the baseline is the overall mean, not the complement). It is a contrast within one model's activations, not model minus model.
- **Data** (p7 App. A): 300 prompts in 10 categories written by Claude Sonnet 3.7; reasoning traces generated by DeepSeek-R1-Distill-Llama-8B; sentences classified by GPT-4o as backtracking or not.
- **Positions:** a negative token offset before the backtracking sentence; "the optimal offset for 10th-layer residual stream of DeepSeek-R1-Distill-Llama-8B is about -13 to -8" (p2, Figure 2 p3), fixed thereafter.
- **Layer:** layer 10 of 32, chosen from the sweep of all 32 layers (p3, "most effective around layer 10"; Figure B.1 p7).
- **Normalisation:** not stated. Figure 2/3 "magnitude" runs 0-15 and 0-20, but whether the vector is unit-normed first is not given.

## How it is applied

- "Added to each model's activations during generation" (p3, section 3.2). Which positions (all generated tokens? prompt too?) is not stated. Strength is a swept "magnitude" (0 to 20, Figure 3 p3; strengths 0, 4, 8 in Figure 1; 0, 4, 8, 12 in Table C.1 p8). No rule for choosing strength on dev data is given; it is shown as a curve.

## Cross-model construction (the item that matters for us)

- This is the paper's central result and the closest to our setting, but it is not a model-difference vector. "Base-derived" vectors are the DoM computed from **Llama-3.1-8B base** activations on the **reasoning model's own traces** (the same tokens run through both models, p3 section 3 and p2 intro), then added to the **reasoning model** (DeepSeek-R1-Distill-Llama-8B, SFT-distilled from a different teacher, not RL). Cosine between base-derived and reasoning-derived vectors is about 0.74 (p3).
- Result (Figure 3, p3): base-derived and reasoning-derived vectors both raise the "Wait" token share in the reasoning model, with comparable performance; **neither induces backtracking in the base model** ("always zero"). The authors conclude the representation exists in the base model and the fine-tuned model repurposes it.
- Consequence for us: the direction that matters lived in the model that has the downstream circuit. Adding a vector to the model that lacks the circuit did nothing. Our vector is added to `dpo` (pre-RL) and contains what changed; whether `dpo` has the downstream "reader" is exactly the open question. Ward gives a prior for a null in the reverse case, though there the vector was a mere concept direction and the "base" had no reasoning behaviour at all.

## What was measured

- Metric: share of generated tokens (words) in {"wait", "hmm"}, Eq. 1 (p2); the 300-trace GPT-4o judge was used for the labels and the keyword metric validated against it: F1 54-64% (Table C.1 p8, vs LLM judge) and about 83% precision against the authors' own labels (p8). Metric is a proxy for backtracking, not accuracy.
- One model pair only (p5 limitations). Error bars: "Gray lines represent error bars of one standard deviation" (Figure 3 caption), over unstated numbers of traces and seeds. Figure 2 is a heatmap of single values with no error.

## Controls (section 3.3, p3; Figure 4 p4)

- Five baselines: overall mean (adding the mean activation), Gaussian noise, self-amplification (activation times a coefficient), deduction-step vector, initializing-step vector. The backtracking vector "significantly outperforms all" (words, no test). Gaussian noise "has a nontrivial effect" on the Wait share, with coherent outputs ("anecdotally", p3). So a random-direction control moves the metric too, which weakens it as a null.
- How the noise is scaled is not given.

## Ambiguous or unsupported

- Application positions; vector norm and magnitude units; number of traces per point; no accuracy or task metric at all (backtracking tokens only); the claim "repurposes pre-existing representations" rests on one model pair and a keyword proxy; the authors say so (p5).
- Neither the logit-lens (Eq. 2, p4) nor the probing (p4) bear on our design.

## How our setting differs

- Their vector is a concept direction (backtracking) from within one model, layer 10 of 32 (31%); ours is a checkpoint difference over all behaviour changes at all positions.
- RL checkpoints of one lineage (shared weights to within 0.36% of ||theta||) versus a distilled model whose weights differ from the base by a large SFT. The RL case should make base-derived vectors more transferable than Ward's case; Venhoff et al. say as much (their v4, see that note).
- 8B versus 32B, with 4-7k token responses; the thinking behaviour in our model is already in `dpo`.

## Changes relative to the earlier description

- The earlier review gave Ward only by abstract. The full text shows: DoM against the overall mean (not backtrack versus non-backtrack), layer 10, offset about -10, and, importantly, no accuracy or benchmark result, only a keyword rate on 300 traces.
- It is not a cross-checkpoint difference; "base-derived" means base activations on the thinking model's text.
