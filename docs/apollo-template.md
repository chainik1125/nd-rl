# Apollo template provenance

The workspace scaffold is adapted from
[ApolloResearch/sample](https://github.com/ApolloResearch/sample) at commit
`1470f6208bf8dcb8f1a0ee7c1797a5d0d8d6e57b` (2024-12-16). The retained MNIST example is
archived under `code/experiments/archived/mnist/`; shared model code and its regression test live
under `code/models/` and `code/tests/`.

The natural-deduction experiments, research summaries, and repository workflow are project-specific
additions rather than results from the template.
