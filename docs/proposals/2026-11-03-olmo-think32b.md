# Proposal 35: does Olmo 3.1 Think 32B's long RL run reach problems its DPO start cannot, within 256 samples?

**Question (Dan):** the 7B pilot ([summary](../../experiment-summaries/2026-11-03-olmo-rlzero-pilot-base-credited-on-all-17-rl-only-solves-within-383-samples-reach-0-at-k512-verdict-inconclusive/README.md))
looked like Yue et al.'s low-RL picture: RL newly solved 17 problems, the base was credited on all of them within 383
samples, and RL lost none.

Does that hold for the largest open RL trajectory?
- Olmo 3.1 Think 32B is one continuous run from its DPO checkpoint.
- Its RL is ≈ 14 % of pretraining GPU-hours.
- In FLOPs it is ≈ 6 × 10⁻³ – 2 × 10⁻², about level with the largest RL tested so far.

This is a screening test, to scale up only if candidates survive.

| step | what |
|---|---|
| models | `Olmo-3-32B-Think-DPO` (the RL start); `Olmo-3.1-32B-Think` at steps 100, 750 (= Olmo 3 Think 32B) and 2,300 (= 3.1) |
| problems | AIME 2025–2026 (≈ 59), checked for overlap with the Think RL data |
| sampling | DPO k 16, each RL checkpoint k 8; symmetric extension to a second success, up to 256, for both reach and reverse candidates |
| grades | AI2's verifier (primary), final-stated-answer only, and a hand-check of every deciding solution |
| outputs | entries, exits and reach against RL ÷ pretraining compute, beside the 7B pilot; a scale-up memo with measured prices |

**Budget** $150 / 120 pod-hours, with a stage gate after the 32B throughput measurement. The projected spend is ≈
$110–120 (the pilot's cost model, not yet measured at 32B). **Run** `olmo-think32b`, `--effort max`, 72 h hard stop.
**Brief:** [followups/BRIEF_olmo-think32b.md](followups/BRIEF_olmo-think32b.md).

**Result (reviewed 2026-11-04):** on 59 AIME 2025–26 problems, pass@1 by RL's verifier goes from 0.716 (DPO) to 0.746 (step 2,300). One problem, aime2025_28, is a reach candidate: in 256 samples the DPO model is credited 7 times by RL's verifier but states the answer once, and under the strict hand reading none of its 7 credited solutions is rigorous. No problem was lost. The pre-registered verdict is "inconclusive" ("no reach at 256" under RL's verifier alone).
