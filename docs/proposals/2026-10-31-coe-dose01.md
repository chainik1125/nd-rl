# Proposal 33: how much RL brings σ back when pretraining holds only 0.1 % of it?

**Question (Dan):** for the midterm write-up, how much RL is needed to reproduce a capability? The figure built from
existing ladders ([write-up](../writeups/2026-10-31-rl-needed-to-reproduce-sigma/README.md)) gives two points and a
bound. The full bases' level before RL, 14 of 106 σ-covered held-out theorems, is reached at 0.39–0.73× pretraining
compute with a 1 % σ dose. Without σ it is not reached by 5.6–9.5×. A 0.1 % arm tells a threshold from a graded
response.

| priority | what | cost (create-or-elicit's estimates) |
|---|---|---|
| 1 | 0.1 % dose arm, 3 seeds × 16 EI rounds, the 1 % arm's exact protocol, per-round held-out reads | ≈ $30–33 |
| 2 | knockout s1 rounds 25–32, only if ≥ $10 remains | ≈ $5 |
| — | the figure regenerated with the new ladders | none |

**Budget** $45 / 90 pod-hours. **Run** `coe-dose01` on agent2, `--effort max`, 72 h hard stop. **Brief:**
[state-env/BRIEF_coe-dose01.md](state-env/BRIEF_coe-dose01.md).

**Result (reviewed 2026-11-01):** the 0.1 % arm reaches the bar on 3 of 3 seeds at 0.69–2.58× RL ÷ pretraining
compute (median 1.37×); knockout s1 does not by 13.2×. The pre-registered reading is "graded".
