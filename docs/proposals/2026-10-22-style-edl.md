# Proposal 32: does EDL rise with proof style when capability is fixed?

**Question (Dan):** EDL scores specific proof strings, so it may charge a model for which valid proof it is taught,
even when the model already proves the theorem. Check it directly with an example. Background:
[the EDL note](../project_strategy/2026-10-22-edl-style-vs-capability.md).

| step | what |
|---|---|
| learners | the K12 bases `stage1_best12_s{0,1,2}_b1200` |
| theorems | 256 tf1200 theorems per learner that it already proves (pass@32 ≥ 0.9), split 128 stream / 128 test by renaming class |
| streams | the same theorems with different valid proofs: the learner's own (two samples, the gates), another seed's, the shortest, an EI ladder's, Kalmár's |
| EDL | prequential blocks 0–128, one fine-tuning algorithm, action tokens only, per proof and per action |
| capability check | pass@32 on the test theorems before and after training on each stream; it must stay ≥ 0.9 |
| style-blind score | EDL recomputed with −log Σ p(y \| x) over every valid proof collected for x |

**Expected if style inflates EDL:** EDL rises from the learner's own proofs, through another seed's, the shortest and
the RL proofs, to Kalmár's, while pass@32 stays flat, and the style-blind score removes most of the spread.
