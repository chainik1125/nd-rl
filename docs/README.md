# Knowledge index

This folder is meant to keep all documents relevant to the project. The folders are:


1. /group_docs: Working principles for the group, research advice, how to collaborate etc..
    - `agent_research_practices/`: how agent-run experiments are proposed, pre-registered, reviewed and recorded.

2. /infra: Descriptions of relevant infrastructure, how to set it up etc...

3. /literature: A place to store information about the relevant literature.
    -  A .bib in (/Users/dmitrymanning-coe/Documents/Research/natural-deduction/nd-rl/references.bib) allows us to cite the relevant papers in any other research notes. 
    - We can also write notes about what the takeaway of a particular paper is for our project to
      assist agents/ourselves in understanding what is available from the current literature and
      what we're trying to do. Note filenames and titles are free-form; a `papers:` YAML list
      associates notes with bibliography entries by citekey.

3. /project_strategy: A place to store notes describing our current goals, the state of the project, etc...

4. /proposals: An idea bank of things we'd like to try. Notes here should be written so that a long running agent run can be set of from them.

5. /research_calls: Transcripts and notes from group meetings. Mostly a reference archive.

6. /theory: A place to store .tex and .md files with theoretical results

7. /writeups: A place for drafts of papers, blog posts, internal notes, etc... 

    - I expect this to mainly be useful for human-human communication.
