Does a looped trunk buy proofs at test time?

What is being compared

Run 198
B1B2B3B4B5B6 6 blocks, 9.56M params
Looped
entrycore Acore B× nexit 2 + 2n blocks per token, 6.40M params

Both models go through the same frozen harness: 300 s of pretraining on proofs of 6 lines or fewer, four rounds of expert iteration on 1,500 targets, then the dev eval. The looped model samples at n = 2 inside the harness, so it applies 6 blocks per token like run 198. Afterwards each checkpoint is sampled again at other loop counts, with no retraining.

Scorecard

Harness score = dev theorems solved with true length 7 or more, 64 samples each. Sweep rows give the looped models at 2 loops, with the best loop count in brackets when it differs. A dash means that stage has not finished.
