Rule Knockouts

Remove one inference rule from the pretraining proofs, run RL, and watch whether the model ever starts using the rule it was never shown. Four rules, one arm each, plus a control that saw everything.

9.6M-parameter transformer · 10 min pretraining · expert iteration unless marked · Lean is the only judge

    RL targets solved over time, every arm

    Cumulative count of the 18,439 RL training targets with at least one Lean-accepted proof, against minutes of RL. The harness measures the held-out dev set only when a run ends, so there is no held-out curve; held-out scores for finished runs are in the table at the bottom.

    Every run

    “Used it” counts distinct Lean-accepted proofs containing the arm's removed rule. “Solved that use it” counts solved targets whose reference proof contains the rule, a proxy for needing it. Held-out dev is 843 theorems at 16 samples each, measured once at the end.
