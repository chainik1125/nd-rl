Do continuous thoughts buy proofs?

What is being compared

theorem statementthought 1thought 2…thought Tproof

Every arm is run 198's untied 6-block model with T extra steps between the statement and the proof. A thought's input is the model's own previous output, not a token. Training draws T from 0 to 8 per batch; the harness samples at T = 8. The arms differ only in what trains the thoughts during the 300 s of pretraining. The plan is each training proof's sequence of inference rules.
