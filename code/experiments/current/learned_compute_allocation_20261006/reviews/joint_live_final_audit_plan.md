## Ready helper and demonstrated coverage

[audit_joint_live_paths.py](audit_joint_live_paths.py) independently reconstructs finite-path reach and stop masses, categorical and greedy-index correctness, greedy stopping, rewards, forced termination, generator work, and controller work. It handles fixed/count/context rules and DEV-frozen convex mixtures. It preserves the tiny FP32 probability excess rather than clipping or renormalizing it; tolerance changes in the approved analysis successor do not change these estimates. Selected age is an additional descriptive readout: newest candidate has age1; at a fixed4 stop the first candidate has age4. It is not a new optimized endpoint.

The helper requires `--root-barrier-release` before opening outcomes from a config whose split is not DEV. This is a procedural safeguard, not a substitute for root authorization. CLI inputs are `--paths`, optional `--counter`, `--budgets`, `--hazards-file`, and a new `--out` file. It imports no scientific integrator. Final registry/provenance validation remains a separate audit step, not silently delegated to this arithmetic helper.

Executed on registered no-cost seed101 DEV200 paths: all544 rows across17 policies reproduce, including counter, context threshold and all three feasible mixtures. Maximum relative work discrepancy is 4.04e-16. Evidence: [DEV check](joint_live_dev_all_policy_preparation_check.json). An earlier base-only run checked352 rows. No final numerical conclusion follows from these DEV checks.
