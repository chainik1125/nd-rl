# Imported June natural-deduction sprints

This directory is an archived snapshot of the complete `code/` tree from
`../earlier-iterations/Natural Deduction LLM/nd_sprint` at source commit `e8766d2` on branch
`sprint3`. It covers the connected June 9–11, 2026 research series:

- propositional proof-length bootstrapping, cap sweeps, protocol comparisons, and depth scaling;
- proof novelty, formal difficulty measures, ICL evaluation, style controls, and nesting controls;
- the first-order natural-deduction generator, tokenizer, verifier, and evaluation scripts.

Python caches, generated datasets, raw result payloads, model checkpoints, and PDFs were omitted.
The original scripts retain their source-repository import and path assumptions; this is a
research snapshot, not an integration into the current package API.
